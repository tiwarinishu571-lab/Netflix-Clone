# Netflix Clone 🎬

A responsive Netflix-inspired landing page built using HTML and CSS. This project recreates the look and feel of a streaming platform's homepage as a frontend development practice project.

## ✨ Features

- Netflix-inspired navigation bar
- Hero section with email input and call-to-action button
- Trending movies poster section
- Feature cards highlighting streaming benefits
- Frequently Asked Questions section
- Footer with useful links and language selector
- Hover effects and CSS transitions
- Responsive layout for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- Google Fonts / Material Symbols

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required.

## 📱 Responsive Design

The layout uses CSS Flexbox and media queries to adapt to smaller screens. Responsive behavior may vary depending on screen size.

## 📌 Project Purpose

This project was created to practice HTML structure, CSS styling, responsive design, and frontend layout development.

**Note:** This is a frontend practice project, not an official Netflix website. Sign-in and membership functionality are not connected to a backend.
